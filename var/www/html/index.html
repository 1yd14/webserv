This server listens on several ports simultaneously via a single epoll loop.

  • Port 8081

Quick test

# Test with curl

curl -v http://localhost:8080/
← 200 OK

curl -v -X POST -H "Content-Length: 5" -d "hello" http://localhost:8080/upload/test.txt
← 201 Created

curl -v -X DELETE http://localhost:8080/upload/test.txt
← 204 No Content
